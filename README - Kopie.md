# TKL Nova-X Configurator

Statische GitHub-Pages-Seite zur Auswahl von Board, Design und Pins. Zum Veröffentlichen den gesamten Ordner in ein GitHub-Repository kopieren und unter **Settings → Pages → Deploy from a branch** den Branch/Ordner auswählen.

Die Seite ist rein statisch und erzeugt eine `tkl-novax-config.json` mit den gewählten Werten.
